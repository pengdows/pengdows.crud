=== SHEET: Read me (xl/worksheets/sheet2.xml)
DATABASE DATA TYPES — CROSS-REFERENCE | 
Scope | 23 named SupportedDatabase products; Unknown excluded; compatible extensions/distributions noted on Sources.
Granularity | Semantic type families, not every possible parameterized declaration or alias. SQL Mappings contains candidate SQL spellings.
N | Documented native/support (reference-level); NOT a tested ADO.NET provider capability.
A | Alias, coercion, approximation, alternate storage, or restricted non-column context. Not semantically identical.
V | Version/engine/configuration-dependent; inspect target server before treating as supported.
E | Extension-dependent; not generally built into the base product.
X | Explicitly unsupported for the target interface/type semantics.
? | Not verified. NEVER interpret ? as unsupported.
Caution | The previous conversational inventory contains inaccuracies; this workbook corrects known major mismatches but is NOT exhaustive documentation verification.
Database version | Product-by-product version is unspecified; type status requires reconciliation against target server release.
Test method | Enumerate server catalogs + GetSchema("DataTypes") + create/insert/read/parameter/roundtrip tests; compare semantics.
Spanner PG | PostgreSQL interface only; subset, not PostgreSQL feature equivalence.
SQLite | Declarations and affinity differ from actual five storage classes.
User-defined types | Unbounded by definition; this matrix tracks capabilities, not each instance of each UDT.
FlatFile | All types unverified until its current parser/catalog/ADO.NET mappings are inspected.
Sources | Official documentation URLs in SQL mappings and Sources. Independent per-cell verification remains necessary.
