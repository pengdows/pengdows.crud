 | How to read the grid
 | Each row is a semantic concept, not a keyword. A cell gives the spelling(s) that realize that concept on that engine, prefixed by its status code.
 | Cells are plain text so the sheet filters and sorts; colour comes from conditional formatting on the leading code.
 | Column F and the per-database count block are formulas — edit a cell's code and the counts update.

 | Scope assumptions
 | Engine-level SQL types only. Whether an ADO.NET provider maps a type correctly is a separate test result and is NOT recorded here.
 | Aurora MySQL / Aurora PostgreSQL columns are generated from the MySQL / PostgreSQL columns, with explicit overrides where Aurora differs (e.g. VECTOR on Aurora MySQL 3).
 | Aurora PostgreSQL extension types ([E]) assume the extension is on the AWS allow-list for the engine version.
