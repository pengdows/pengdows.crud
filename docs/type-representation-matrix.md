# Type representation matrix

Generated by `tools/datatype-probe/gen_representation_doc.py` from the live fidelity matrix and the generator's
tables. Do not edit by hand: change the generator and re-run it.

Each row is a type the library reads and writes. The **CLR type** is the property type, and the **DbType** is the
type the cell's parameter is declared with. Each database column is the native column type that holds the value
when the database has one, as the live integration matrix created it and read it back (a value that didn't
round-trip is not shown as PASS). A cell is `—` when the server refused every spelling the probe tried for it;
that is not proof the database lacks the type, only that none of the candidate spellings was accepted. **open**
marks a cell where the probe found a type the database accepts and the library refuses it for a stated reason.
The **open** cells are the work that remains; a `—` cell becomes work if a spelling the probe missed turns out to work.
